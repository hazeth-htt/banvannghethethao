OBJECTIVE

Redesign the existing Ban Văn nghệ Thể thao – Đoàn Đại học Bách khoa Hà Nội website.

IMPORTANT: Do NOT redesign the information architecture or remove existing sections/content.

Keep the current:

Hero content

Organizational structure section
7 clubs section

The main task is to completely redesign the visual language and art direction.

The current implementation looks too much like an AI/SaaS/product landing page: excessive glowing borders, dashboard-like cards, pills, gradients, neon effects, generic icons, and overly symmetrical layouts.

Transform it into a premium creative institution / cultural organization / visual arts studio website inspired by the design language of the provided Prisma reference.

The website should feel like:

A contemporary creative studio / cultural collective / art direction portfolio — not an AI startup.

1. CORE VISUAL DIRECTION

Use the Prisma reference as the visual design reference, NOT as a content or layout reference.

The design language should be:

Minimal but expressive

Avoid filling every area with UI elements.

Use:

large empty spaces
oversized typography
strong image composition
subtle borders
large visual blocks
asymmetrical layouts
typography as a graphic element

Do NOT make every section look like a collection of cards.

2. KEEP THE EXISTING COLOR PALETTE

Do NOT replace the existing purple / magenta color palette.

Keep the colors currently established in the website/Figma design.

The visual system should continue using:

deep black / near-black background
dark purple
violet
magenta
pink-purple accent
white / off-white typography

However, change how the colors are used.

Current problem

The existing implementation uses purple as:

glowing borders
neon shadows
card outlines
gradients everywhere
glowing buttons

This creates a generic AI aesthetic.

New approach

Purple should behave more like an art-direction accent.

Use it selectively for:

important typography
thin lines
section markers
hover states
small labels
editorial details
image overlays
occasional large color blocks

Avoid excessive neon glow.

IMPORTANT

Reduce:

box-shadow glow
neon borders
purple gradients
excessive glassmorphism
glowing cards

Purple should feel rich and cinematic, not synthetic.

3. TYPOGRAPHY

Typography is one of the most important changes.

The current website feels too much like a SaaS product because typography is too UI-oriented.

Use a combination of:

Primary sans-serif

Use a modern grotesk / clean sans-serif for:

navigation
descriptions
metadata
buttons
body text

The typography should feel similar to the restrained typography of the Prisma reference.

Display typography

Use a distinctive display serif or editorial italic font for selected words.

Do NOT use the serif everywhere.

Use it selectively for:

section introductions
emphasis words
artistic statements
editorial phrases

For example:

Nơi nghệ thuật gặp gỡ

could visually emphasize:

nghệ thuật

with an italic editorial serif.
